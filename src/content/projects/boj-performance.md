> 지원 대상 서비스가 종료되어 유지보수를 멈추고 저장소를 아카이브했습니다.

## 서비스

백준 온라인 저지에서 문제를 풀면 실행 시간과 메모리가 숫자로만 나옵니다. 그 숫자가 좋은 건지 나쁜 건지는 알 수 없습니다.

이 확장은 채점 현황 페이지에서 **전체 제출자 분포 안의 내 위치**를 막대 그래프로 보여줬습니다. "상위 15.20% (최근 200건 기준)"처럼 기준을 함께 표시해, 숫자를 해석 가능한 형태로 바꾸는 것이 목적이었습니다.

Chrome 57명, 웨일 54명, Firefox 1명 — 세 스토어 합쳐 **누적 112명**이 설치했습니다.

## 만들면서 정한 것

### 비교 대상을 같은 언어로 한정

C++ 제출과 Python 제출을 한 분포에 넣으면 실행 시간 비교가 의미를 잃습니다. 백준 페이지 상단의 언어 필터를 감지해, 필터를 바꾸면 **그래프도 해당 언어 통계로 자동 갱신**되게 했습니다.

### 표본 범위를 화면에 적었다

"상위 15.20%"만 쓰면 무엇을 기준으로 한 건지 알 수 없습니다. "최근 200건 기준"을 항상 같이 표시해, 숫자를 과장하지 않고 그대로 읽히게 했습니다.

### 남의 확장과 충돌하지 않게

백준 사용자는 `boj-extended` 같은 확장을 이미 쓰는 경우가 많습니다. OS 다크 모드뿐 아니라 **그 확장의 다크 모드 설정까지 감지**해 테마를 맞췄습니다.

## 왜 멈췄나

기능을 지탱하던 외부 서비스가 종료되면서 데이터 출처가 사라졌습니다. 억지로 유지하는 대신 저장소에 상태를 명시하고 아카이브했습니다.
